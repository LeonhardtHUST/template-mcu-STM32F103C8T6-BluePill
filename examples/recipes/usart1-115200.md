## ① 对应 IP / 配置（抄进 `.ioc` 的内容）

**本模板 `.ioc` 当前未启用 USART1**（只有 `NVIC` / `RCC` / `SYS` 三个 IP、PC13 + PA13 + PA14 三根引脚）。
要用本示例必须先在 **CubeMX GUI** 里加（不要照着手改 `.ioc` 文本猜枚举）：

| 配置 | 值 | 说明 |
| ---- | -- | ---- |
| IP | `USART1`，Mode = Asynchronous | `Mcu.IP3=USART1`、`Mcu.IPNb=4` |
| 引脚 | PA9 = `USART1_TX`，PA10 = `USART1_RX` | 芯片级默认复用，见 [`board-pinout.md`](../../docs/bluepill/board-pinout.md) §4.4 |
| 参数 | 115200 / 8 data bits / no parity / 1 stop bit | 示例约定；实际值以 `.ioc` 为准 |
| 时钟 | 当前 HSI 8 MHz；如切 HSE+PLL 72 MHz 需重新核对波特率分频 | `.ioc` 的 RCC 决定 |

生成后 `main.c` 必须出现 `MX_USART1_UART_Init()` 与 `UART_HandleTypeDef huart1;`。
手改 `.ioc` 时务必同步 `USART1.IPParameters` 白名单（D3），信号名用 `S_` 前缀（D4），
且**改完必须做第 2 步的 L4 核验**——CubeMX 的错误是静默的（D5）。

## ② 可复用文件清单（只拷源码）

| 文件 | 处理 | 理由 |
| ---- | ---- | ---- |
| [`../usart1-115200/usart1_echo.c`](../usart1-115200/usart1_echo.c) / `usart1_echo.h` | **可拷** | 自研、只用 HAL UART 轮询 API，句柄由调用方传入，不绑死 `huart1` 名字 |
| `Core/Inc/bluepill.h` 的 `BP_USART1_TX_*` / `BP_USART1_RX_*` | **用现成宏** | 只描述板上接线，模式 / 波特率仍归 `.ioc` |
| 外部例程的 `usart.c` / `usart.h` | 只摘参数，不整文件拷 | 本模板 `CoupleFile=false`，`MX_USART1_UART_Init()` 集中在 `main.c` |
| `main.h` / `stm32f1xx_it.c` / `stm32f1xx_hal_msp.c` / `stm32f1xx_hal_conf.h` | 不拷 | CubeMX 覆盖生成；缺 `HAL_UART_MODULE_ENABLED` 就在 `.ioc` 加外设再生成 |
| `Core/Src/stdio_port.c` 的 `__io_putchar` / `__io_getchar` | 可选：需要 `printf` 重定向时**另写用户源码** | 适配层本身不初始化 USART；不要把逻辑写回会被覆盖的 `syscalls.c` |
| `Drivers/**` / `startup_*.s` / `*.ld` / `system_stm32f1xx.c` | 丢掉 | framework 提供，重复定义风险 |
| `.uvprojx` / `.uvoptx` / `*.hex` / MDK-ARM/ | 丢掉 | Keil 样板 |

## ③ 与 PlatformIO 的差异

| 项 | 外部 CubeIDE / MDK 例程 | 本模板 |
| -- | ---------------------- | ------ |
| 工具链 | CubeIDE GCC / Keil ARMCC（`.uvprojx`） | PlatformIO + GCC ARM（`platformio.ini`） |
| CubeMX Toolchain 选项 | `MDK-ARM V5.32` 等 | `Makefile`（只为产出 `Core/`） |
| HAL / CMSIS | 例程目录自带 | `framework-stm32cubef1@1.8.7` |
| `ProjectManager.CoupleFile` | 常为 `true`（独立 `usart.c`） | `false`（初始化集中在 `main.c`） |
| 浮点 printf | 例程可能默认开 | newlib-nano 默认不含 `%f`，需 `-Wl,-u,_printf_float` |
| **禁止** | 对 `examples/usart1-115200/` 跑 `pio run` | 该目录没有 `platformio.ini`，也不在 `src_dir` |

## ④ 接入步骤 + 已知坑（统一 5 步）

1. **把外设配置抄进根目录 `.ioc`**：按 ① 在 CubeMX GUI 启用 USART1，保存并 `project generate`。
2. **核验生成物（L4）**：日志无 `Cannot map` / `OptionalMessage_ERROR`；
   `main.c` 里有 `MX_USART1_UART_Init()`、`main.h` 有 HAL UART 相关包含；
   `stm32f1xx_hal_conf.h` 里有 `HAL_UART_MODULE_ENABLED`。
3. **只拷源码**：`usart1_echo.c/.h` 拷进 `Core/`（或加 `-I`），调用放进 `main.c` 的 USER CODE 块；
   句柄传 `&huart1`；Keil 样板、`Drivers/` 一律丢。
4. **`pio run`（L3）**：记录 PlatformIO 报告的 Flash / RAM 字节数；
   工程源码用 `-Werror`，未使用的变量 / 参数会直接报错。
5. **按 L2 / L3 / L5 验证**：本示例无可主机编译的纯 C 逻辑，L2 不适用；
   串口是运行时行为，**必须 L5 实板**确认（USB 转串口发字符能看到回显、示波器看波形）。
   「编译通过」不等于「能用」。

**已知坑**：

- **`.ioc` 没启用 USART1 就编译** → `huart1` 未定义；这是最常见的失败原因。
- **手改 `.ioc` 静默丢外设**：信号名写错仍返回生成成功，只留一行 `Cannot map`（D5）。
- **TX/RX 接反或忘共地**：USB 转串口交叉接 TX↔RX、GND↔GND。
- **PA11/PA12 是 USB，别和串口混**；PA9/PA10 才是 USART1（`board-pinout.md` §4.4）。
- **轮询会阻塞**：`usart1_echo_poll_byte()` 的 `timeout_ms` 别设太大，超时返回 0 属正常。
- **`huart1` 名字**：CubeMX 生成的全局句柄名以实际生成物为准，本示例刻意不写死。
